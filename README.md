# Ebook HTML Converter

A Dart command-line tool to convert source HTML files into clean, ebook-ready HTML suitable for conversion with Calibre.

# Setup

Source HTML has to be download from [torat emet free ware](https://www.toratemetfreeware.com/files/online.zip), extracted, and moved to this repo under `source/torat-emet`. It will be read from there.
